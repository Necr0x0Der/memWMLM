# Статус

Эксперимент подготовлен для запуска пользователем на GPU-машине.
Результатов Qwen3-4B по этому протоколу пока нет.

Локально проверены аудит исходного датасета (408/72/96), точное совпадение длин
продолжений на доступном токенизаторе Qwen3-1.7B и интеграционный процесс на
маленькой случайной Qwen. Проверка длин повторяется extractor на pinned 4B.
Тесты проверяют отсутствие LM-head/generation и утечки targets в prompts,
padding, запрет обрезания, фиксацию всех проб до test, расчёт парных разниц и
отказ при несовпадении длины.

После настоящего прогона автоматически появится
`artifacts/probes-qwen3-4b/SUMMARY.md`; его числа будут результатами эксперимента.
Старые метрики question-conditioned-states сюда не переносятся.
